# Cultural Fest Community Portal

A simple web-based application for managing and viewing cultural events in a community. Users can browse events, filter by category, search events, and register for participation.

---

## Features

- View upcoming cultural events
- Filter events by category (Music, Dance, Workshop, Art)
- Search events by name
- Register for events using a form
- Dynamic seat update after registration
- jQuery-based UI animations
- Async data loading using Fetch API

---

## Technologies Used

- HTML
- CSS
- JavaScript (ES6)
- jQuery
- JSON (for event data)

## How to Run the Project

1. Download or clone the repository
2. Open the folder in VS Code
3. Install **Live Server extension**
4. Right-click on `index.html`
5. Click **"Open with Live Server"**

---

## Output

- Event cards will be displayed dynamically
- Users can register for events
- Seats will decrease after successful registration
- Filters and search will update results instantly
